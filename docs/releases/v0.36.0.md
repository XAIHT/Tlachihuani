# Tlachihuani 0.36.0

> Historical record. Latest version: **[0.38.0](v0.38.0.md)**.

**Version 0.36.0.** Documentation updated 17 November 2026, as requested
by Angela López Mendoza. This version carries forward everything in
[0.3.3](v0.3.3.md) and adds the Remote-Controller plane and a forced sign-in for
XT's **Open workspace**.

## Remote-Controller (Tlamatini-RC)

- A third Windows service, `Tlachihuani.RemoteController`
  (`RCServer/Tlachihuani.RC.Server.exe`), hosts the Tlamatini-RC web client,
  enrollment, device grants, sessions, operation receipts, events and schedules.
  The implemented profile is local-only, `127.0.0.1:12481` by default; Torrenter's
  port 12064 stays reserved. See [Remote-Controller](../remote-controller.md).
- XT's **Remote-Controller…** dialog grants per-account permissions (view status,
  conversation, full mobile workspace, start, stop and schedules). Application
  launch runs through XT in the signed-in Windows session.
- Approvals are synchronized across the main English and Spanish chats and RC, and
  answers are atomic, so a stale prompt cannot affect a newer approval. See the
  [approval synchronization record](../verification/2026-11-15-approval-sync.md)
  and the [hardening review](../verification/2026-11-15-hardening-review.md).
- Hosted remote control is development work: production remote transport,
  public deployment and external-phone acceptance remain explicit gates. See the
  [predeployment checklist](../remote-control-predeployment-checklist.md).

## Torrenter workspace sign-in

XT **Services → REST workspace → Open workspace** now always opens the Tlamatini
login page first, even when the browser is already signed in. Signing in there
replaces the browser's Tlamatini session, so the queue shown belongs only to the
account that just signed in. Another tab still showing the previous account
reports the change and hides its queue instead of mixing queues. With both
editions running, each choice leads to its own login page. **Access → Open
downloads** keeps the current login. See the [Torrenter guide](../torrenter.md).

## Installation and packaging

The matching archive is `Tlachihuani-0.36.0-windows-x64.zip`, with its
`.zip.sha256`. Extract everything, open `START-HERE.html`, then run Installer.exe
and confirm **0.36.0** on Review. Follow the [setup guide](../../packaging/setup/README.md).
Setup behavior is unchanged: optional XT at Windows sign-in, Start/Desktop
shortcuts, and all services stopped/Manual until **Start Services**.

`Directory.Build.props` and the internal project lock references declare
**0.36.0**. `Build-Release.cmd` selects the numeric `v0.36.0` tag and writes the
ZIP to `dist`. See [release building](../release-building.md).

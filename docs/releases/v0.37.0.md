# Tlachihuani 0.37.0

> Historical record. Latest version: **[0.38.0](v0.38.0.md)**.

**Version 0.37.0.** Documentation updated 19 November 2026, as requested
by Angela López Mendoza. This version carries forward everything in
[0.36.0](v0.36.0.md) and adds XT's own log and the xaiht.org link.

## Tlachihuani.log and See log

- XT now writes **Tlachihuani.log** in `%LOCALAPPDATA%\XAIHT\Tlachihuani` for each
  Windows user: its start and exit, the xaiht.org link's state changes and every
  message received from xaiht.org, as readable JSON.
- **Services → See log** shows the log inside XT and follows new lines, with
  **Copy all**, **Open folder** and **Refresh**.

## Messages from xaiht.org

- A new **xaiht.org** tab in **Services** connects this computer to the
  **Tlamatini-RC** page on xaiht.org with a one-time computer key.
- XT asks xaiht.org for messages over outgoing HTTPS, so the computer is reachable
  from any network without opening a port, and the page shows it **Online** while
  XT is asking.
- **SEND** on the page delivers a JSON message that XT writes to Tlachihuani.log;
  the page shows **Written to Tlachihuani.log**. Messages sent while the computer
  is offline wait until it connects. In this version messages are only logged.

See the [xaiht.org link guide](../xaiht-link.md). The website side is in the XAIHT
`web-app` repository and is deployed separately.

## Installation and packaging

The matching archive is `Tlachihuani-0.37.0-windows-x64.zip`, with its
`.zip.sha256`. The installer does not install over an existing installation:
**Stop Services**, **Exit tray**, uninstall the current Tlachihuani from
**Settings → Apps → Installed apps**, then extract everything, open
`START-HERE.html`, run Installer.exe as the same Windows user and confirm
**0.37.0** on Review. Your downloads and retained identities stay on disk. Follow
the [setup guide](../../packaging/setup/README.md).

`Directory.Build.props` and the internal project lock references declare
**0.37.0**. `Build-Release.cmd` selects the numeric `v0.37.0` tag and builds the
current checkout into `dist`. See [release building](../release-building.md).

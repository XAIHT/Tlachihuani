# Tlachihuani 1.0.0 · first official release

**Latest version: 1.0.0, released 25 November 2026.** This is Tlachihuani's first
official release, after a series of pre-releases from 0.1.0 to 0.40.1.
Documentation updated as requested by Angela López Mendoza. It carries forward
everything in [0.38.0](v0.38.0.md) and the pre-releases after it, and adds Flow
Pills.

## New in 1.0.0: Flow Pills

**XT → Flow Pills…** opens the flows Tlamatini makes, draws them as Tlamatini drew
them, and runs each one on its own: agentic flows (`.flw`) from the Agentic Control
Panel with Tlamatini's own agents, and flow pills (`.fpmt`) from the Prompt Flow
Panel with the models Tlamatini is configured with. Up to 256 flows run at once by
default, each on its own thread and in its own Windows job, with every log followed
live. A flow that never ends keeps running, and closing the window can leave the
flows running. See [Flow Pills](../flow-pills.md).

## Since 0.38.0

- **0.39.0 · stable log browsing.** **See log** pauses while you browse, reads the
  log in pages, keeps the opened file through rotation and searches every retained
  log file. See the [log viewer guide](../log-viewer.md).
- **0.40.0 · prompts from your phone.** The website sends typed prompts to an
  explicitly approved Tlamatini account through XT's outgoing HTTPS connection and
  the local Remote-Controller, and returns real answers. **Start Services** no longer
  reports a false startup failure while the services are still becoming ready, and a
  failed service action offers a copyable report, also saved beside Tlachihuani.log
  as `Last-service-error.txt`. See the [xaiht.org link](../xaiht-link.md).
- **0.40.1 · large answers.** A full answer larger than 8 MB is now refused once with
  a named reason (`response_too_large`), instead of failing silently and being retried
  every minute.

What came before is in the [0.38.0](v0.38.0.md), [0.37.0](v0.37.0.md),
[0.36.0](v0.36.0.md) and [0.3.3](v0.3.3.md) notes.

## Install or upgrade

Download `Tlachihuani-1.0.0-windows-x64.zip` and its `.zip.sha256` from the GitHub
release. The installer does not install over an existing installation. Coming from
any pre-release: **Stop Services**, **Exit tray**, uninstall Tlachihuani from
**Settings → Apps → Installed apps**, then extract everything, open
`START-HERE.html`, run Installer.exe as the same Windows user and confirm **1.0.0**
on Review. Your downloads, retained identities and job journal stay on disk. Follow
the [setup guide](../../packaging/setup/README.md).

`Directory.Build.props` and the internal project lock references declare **1.0.0**.
`Build-Release.cmd` selects the numeric `v1.0.0` tag and builds the current checkout
into `dist`. See [release building](../release-building.md).
